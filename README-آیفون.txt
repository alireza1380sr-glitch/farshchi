اپلیکیشن فرشچی — نسخه سازگار با آیفون

نکته مهم:
فایل HTML به‌تنهایی وقتی مستقیماً از برنامه Files باز شود، ممکن است در iOS به‌دلیل محدودیت‌های اجرای فایل محلی، ذخیره‌سازی یا دوربین درست کار نکند. برای استفاده پایدار و نصب روی صفحه اصلی، این پوشه باید روی یک میزبان HTTPS قرار بگیرد.

روش استفاده:
1) فایل ZIP را استخراج کنید.
2) تمام فایل‌های داخل پوشه را با حفظ ساختار روی یک میزبان HTTPS استاتیک قرار دهید (مثلاً GitHub Pages یا هاست خودتان).
3) آدرس index.html را در Safari آیفون باز کنید.
4) از دکمه Share، گزینه Add to Home Screen / افزودن به صفحه اصلی را بزنید.
5) برنامه را از آیکن «فرشچی» روی صفحه اصلی باز کنید.

فایل‌ها:
- index.html: برنامه
- manifest.webmanifest: مشخصات برنامه وب
- sw.js: کش و پشتیبانی آفلاین پس از اولین بارگذاری
- icon-192.png و icon-512.png: آیکن برنامه

رمز پیش‌فرض موجود در کد اصلی: 1234
پیش از وارد کردن اطلاعات واقعی، از بخش پشتیبان‌گیری برنامه خروجی JSON بگیرید و آن را در محل امن نگه دارید.
